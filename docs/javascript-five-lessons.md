# Пять практических уроков по JavaScript

## Урок 1. Преобразование массивов: map, filter и reduce

Массивы встречаются почти в любой JavaScript-программе: это список товаров, пользователей, сообщений или результатов поиска. Вместо ручного перебора через обычный цикл часто удобнее использовать встроенные методы `map`, `filter` и `reduce`.

Метод `map` создаёт новый массив и преобразует каждый его элемент. Допустим, у нас есть цены без скидки:

```js
const prices = [100, 250, 400];
const discounted = prices.map(price => price * 0.9);
// [90, 225, 360]
```

Исходный массив при этом не изменяется. Это полезно, потому что данные остаются предсказуемыми.

Метод `filter` тоже возвращает новый массив, но оставляет только элементы, которые прошли проверку:

```js
const numbers = [3, 8, 12, 5, 20];
const largeNumbers = numbers.filter(number => number >= 10);
// [12, 20]
```

А `reduce` сводит весь массив к одному результату. Например, с его помощью можно посчитать сумму:

```js
const total = prices.reduce((sum, price) => sum + price, 0);
// 750
```

Первый аргумент функции — накопленный результат, второй — текущий элемент. Число `0` задаёт начальное значение суммы.

Главное правило простое: `map` используйте для преобразования, `filter` — для отбора, а `reduce` — когда из набора значений нужно получить один итог. Эти методы можно объединять в цепочки, но слишком длинную цепочку лучше разбить на понятные шаги.

## Урок 2. Полезные методы строк

Строки в JavaScript имеют множество встроенных методов. Они позволяют очищать пользовательский ввод, искать текст и разбивать большие строки на части.

Метод `trim` удаляет пробелы и переносы строк по краям:

```js
const rawName = '   Дмитрий   ';
const name = rawName.trim();
// 'Дмитрий'
```

Методы `includes`, `startsWith` и `endsWith` отвечают на вопросы о содержимом строки:

```js
const filename = 'lesson.js';

filename.includes('lesson'); // true
filename.startsWith('les');  // true
filename.endsWith('.js');    // true
```

Если нужно получить часть строки, применяется `slice`. Первый индекс включается в результат, а второй — нет:

```js
const language = 'JavaScript';
language.slice(0, 4); // 'Java'
language.slice(4);    // 'Script'
```

Метод `replaceAll` заменяет все найденные совпадения, а `split` превращает строку в массив:

```js
const tags = 'javascript,frontend,web';
const tagList = tags.split(',');
// ['javascript', 'frontend', 'web']

const safeTitle = 'Мой новый урок'.replaceAll(' ', '-');
// 'Мой-новый-урок'
```

Важно помнить, что строки неизменяемы. Метод не исправляет старую строку, а возвращает новую. Поэтому результат обычно нужно присвоить переменной.

На практике методы строк часто объединяют. Например, ввод можно сначала очистить через `trim`, затем привести к нижнему регистру методом `toLowerCase` и только после этого сравнивать. Так проверка меньше зависит от случайных пробелов и регистра букв.

## Урок 3. Работа с объектами через Object.keys, Object.values и Object.entries

Объект хранит данные в виде пар «ключ — значение». Например, карточку товара можно представить так:

```js
const product = {
  title: 'Клавиатура',
  price: 5000,
  inStock: true,
};
```

Метод `Object.keys` возвращает массив ключей, а `Object.values` — массив значений:

```js
Object.keys(product);
// ['title', 'price', 'inStock']

Object.values(product);
// ['Клавиатура', 5000, true]
```

Метод `Object.entries` особенно удобен, когда нужно перебрать ключи вместе со значениями:

```js
for (const [key, value] of Object.entries(product)) {
  console.log(`${key}: ${value}`);
}
```

Запись `[key, value]` называется деструктуризацией массива. Она сразу раскладывает каждую пару по двум переменным.

Обратную операцию выполняет `Object.fromEntries`. Он превращает массив пар обратно в объект:

```js
const settings = [
  ['theme', 'dark'],
  ['fontSize', 18],
];

const settingsObject = Object.fromEntries(settings);
// { theme: 'dark', fontSize: 18 }
```

Для копирования объекта и изменения отдельных полей часто применяют оператор расширения:

```js
const updatedProduct = {
  ...product,
  price: 4500,
};
```

Старый объект остаётся прежним, а новый получает все его поля и обновлённую цену. Такой подход особенно полезен в интерфейсах, где изменение исходного объекта может привести к неожиданным побочным эффектам.

## Урок 4. Функции, параметры и функции обратного вызова

Функция — это самостоятельный блок кода, который можно вызвать много раз. В JavaScript функции можно объявлять несколькими способами.

Обычное объявление выглядит так:

```js
function calculatePrice(price, discount = 0) {
  return price * (1 - discount);
}

calculatePrice(1000, 0.2); // 800
calculatePrice(1000);      // 1000
```

Параметр `discount = 0` имеет значение по умолчанию. Оно применяется, если второй аргумент не передан.

Стрелочная функция записывается короче:

```js
const double = number => number * 2;
```

Если параметров несколько, нужны круглые скобки. Если тело состоит из одной операции, результат возвращается автоматически.

Функцию можно передать в другую функцию как обычное значение. Такая переданная функция называется callback, или функция обратного вызова:

```js
function processUser(name, callback) {
  const normalizedName = name.trim();
  callback(normalizedName);
}

processUser('  Анна  ', user => {
  console.log(`Привет, ${user}!`);
});
```

Именно callback-функции передаются в `map`, `filter`, обработчики кнопок и таймеры.

Если количество аргументов заранее неизвестно, используется rest-параметр:

```js
function sum(...numbers) {
  return numbers.reduce((total, number) => total + number, 0);
}

sum(2, 4, 6, 8); // 20
```

Rest-параметр собирает аргументы в массив. Важно не путать его с оператором расширения: синтаксис одинаковый, но внутри параметров он собирает значения, а при вызове функции — раскрывает их.

## Урок 5. Стандартные объекты JSON, Math и Date

В JavaScript есть глобальные встроенные объекты, которые решают распространённые задачи без дополнительных библиотек.

Объект `JSON` используется для преобразования данных в текст и обратно. Метод `JSON.stringify` превращает объект в JSON-строку:

```js
const user = { name: 'Ирина', level: 3 };
const json = JSON.stringify(user);
// '{"name":"Ирина","level":3}'
```

Метод `JSON.parse` выполняет обратное преобразование:

```js
const restoredUser = JSON.parse(json);
console.log(restoredUser.name); // 'Ирина'
```

Разбирать через `JSON.parse` следует только корректный JSON. При повреждённой строке метод выбросит ошибку, поэтому данные из ненадёжного источника обычно обрабатывают через `try...catch`.

Объект `Math` содержит математические функции. `Math.round` округляет до ближайшего целого, `Math.floor` — вниз, а `Math.ceil` — вверх:

```js
Math.round(4.6); // 5
Math.floor(4.9); // 4
Math.ceil(4.1);  // 5
```

Для поиска границ используются `Math.min` и `Math.max`. Массив перед ними раскрывают оператором `...`:

```js
const scores = [12, 45, 27];
Math.max(...scores); // 45
```

Объект `Date` представляет дату и время:

```js
const now = new Date();
const formatted = now.toLocaleDateString('ru-RU');
```

Для хранения и передачи даты часто используют `toISOString`, потому что этот формат однозначен и не зависит от языка интерфейса. А для показа пользователю удобны `toLocaleDateString` и `toLocaleString`, которые учитывают выбранную локаль.

Эти стандартные объекты покрывают множество повседневных задач: сохранение структурированных данных, вычисления, округление и форматирование времени. Главное — понимать, какой тип данных принимает метод и что именно он возвращает.
